Significance Analysis

With a validated NTuple in hand and a clean B⁺ signal from Part 2, we now turn to the main physics goal: searching for structures in the mass spectrum from B⁺ → J/ψ φ K⁺ decays. This is where the original analysis found two exotic resonance candidates above the threshold. Our task is to reproduce the full significance pipeline — per-bin B mass fits, a binned χ² fit to the Δm spectrum, and a Toy MC correction for the look-elsewhere effect.

The Observable: Δm

Rather than working directly with or , we use the variable

This definition follows the CDF and LHCb convention and has two important advantages. First, many systematic uncertainties on the absolute mass scale — tracker alignment, magnetic field, momentum scale — cancel in the difference. Second, the kinematic threshold of the spectrum starts exactly at , giving a well-defined lower edge that the background model can anchor to.

The search window is GeV, divided into 20 MeV bins. This spans from the threshold up to a point well above the second candidate structure near 1.22 GeV.

Step 1: Per-Bin B Mass Fits

The yield in each Δm bin is not simply a count of entries. Because we are working with B candidates rather than signal-only events, each Δm bin contains both real B⁺ decays and combinatorial background under the B mass peak. We extract the signal yield per bin with an unbinned RooFit mass fit inside each Δm slice.

The model is simple by design:

  • Signal: a single Gaussian with mean fixed to the PDG B⁺ mass (5.279 GeV) and width fixed to the MC-predicted resolution (~10 MeV). Both parameters are held constant — only the yield floats.
  • Background: a first-order Chebyshev polynomial over the fit range 5.20–5.40 GeV.

Fixing the signal shape (rather than floating mean and width) is the right choice here: with only O(10–50) signal events per 20 MeV Δm bin, letting the mean and width float would cause the fit to chase statistical fluctuations and produce biased yields. The MC resolution as a function of Δm is encoded in sigma_B_MC(), which you should replace with your own per-bin resolution table once you have MC samples processed.

Bins with fewer than 10 entries in the B mass window are skipped (yield set to zero with zero error), since the fit cannot converge reliably on so few events.

After fitting all 40 bins, the yields and their uncertainties are saved to dm_spectrum.npz. The --load-spectrum flag lets you skip this step on subsequent runs, which is important because it takes several minutes to loop over the full tree 40 times.

Step 2: Efficiency Correction

In the original analysis, the B⁺ yield in each Δm bin is divided by the relative reconstruction efficiency derived from signal Monte Carlo. This corrects for the fact that the B decay angular distributions and the detector acceptance vary across the mass spectrum, potentially mimicking or masking structures.

The corrected yield plotted on the y-axis is per 20 MeV.

Step 5: χ² Minimization — Grid Scan + L-BFGS-B

A naive gradient descent from a single starting point will frequently get stuck in local minima, especially for the one-peak fit where the Y(4140) sits close to the steeply-rising phase-space threshold. The script addresses this with a coarse grid scan before the final refinement.

For the one-peak fit, the mass is scanned on a dense grid in [1.030, 1.568] GeV (denser near Y(4140) at ~1.051 GeV) and the width over [10, 80] MeV. The best grid point is used as the starting value for scipy.optimize.minimize with L-BFGS-B:

One subtlety: if the one-peak fit finds a significance ≥ 5σ, the mass and width of the first peak are fixed when fitting the two-peak hypothesis. This follows the original analysis prescription: once the first structure is established, the background for the second-peak search is defined as PS + fixed BW₁, not pure PS. This matters because letting both peaks float simultaneously introduces parameter degeneracies that inflate the two-peak Δχ² artificially.

Step 7: Toy MC Significance (Look-Elsewhere Effect)

The local significance from Wilks’ theorem does not account for the look-elsewhere effect (LEE): we searched for a peak anywhere in the [1.008, 1.568] GeV window, so the true global p-value is larger than the local one by a factor roughly equal to the number of independent resolution elements in the search range (≈ 28 for a 10 MeV resolution over 560 MeV).

The Toy MC corrects for this. The procedure:

  1. Generate pseudo-experiments from the pure phase-space background, each with the same number of events as observed in the data search window.
  2. For each toy, scan the full search window for the maximum Δχ² (exactly as done on data, including the mass-width grid scan).
  3. Count the fraction of toys where . This fraction is the global p-value.

The toys are run in parallel with Python’s multiprocessing.Pool. Each worker receives a unique seed (seed + i) for full reproducibility regardless of worker count or scheduling order.

The original analysis used 50.5 million toys for peak 1 and 9.8 million for peak 2. On a single laptop this would take weeks. The intended production workflow is to run on an HTCondor cluster, splitting the toy jobs across many cores.

What’s Next
